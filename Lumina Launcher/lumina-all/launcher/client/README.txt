Сюда кладутся собранные jar клиента Lumina. Имя файла говорит лаунчеру, для каких версий он:

  lumina-1.0.0+mc1.21.11.jar          одна версия
  lumina-1.0.0+mc1.14-1.21.10.jar     диапазон версий (включительно)
  lumina-1.0.0+mc1.8.9-1.12.2.jar     Legacy Fabric

Пункт "Fabric + Lumina Client" в лаунчере включается только если для выбранной версии есть подходящий jar.
